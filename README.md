# 성간 요격대 (Interstellar Interceptor)

우주 공간에서 몰려오는 적 편대를 요격하는 3인칭 3D 슈팅 게임입니다. (three.js, 파일 하나로 동작)

- 스테이지 20개. 5·10·15·20 스테이지는 모함 아르고스와 싸우는 보스 스테이지입니다.
- 적은 세 종류입니다. 빨간 기체는 조준탄, 노란 기체는 유도미사일, 파란 기체는 3초 차징 후 레이저를 쏩니다.
- 부스터로 돌진하고, 엔진 코어를 먹어 게이지를 채웁니다.
- 격납고에서 크리스탈로 기체 6종, 무기 5종(블래스터·산탄포·유도 미사일·집속 레이저·레일건)을 구매하고 강화·도색합니다.
- 튜토리얼이 있고, 설정에서 음악·효과음·화면 흔들림·진동·고화질·빛 번짐을 조절할 수 있습니다.

## 조작
| | PC | 모바일 (가로 화면) |
|---|---|---|
| 이동 | WASD / 방향키 | 왼쪽 화면 드래그 (조이스틱) |
| 발사 | Space / J (누르고 있으면 연사) | 발사 버튼 |
| 부스터 | Shift / K | 부스터 버튼 |
| 설정·일시정지 | Esc | 오른쪽 위 설정 버튼 |

## 실행
`index.html`을 브라우저로 열면 됩니다. three.js를 CDN에서 불러오므로 인터넷 연결이 필요합니다.

`main` 브랜치에 올리면 GitHub Pages로 자동 배포됩니다. (`.github/workflows/deploy.yml`)
저장소 Settings → Pages → Source를 **GitHub Actions**로 한 번 설정해야 합니다.
